## About
**Cutter's Delight** is an add-on for <a href="https://modrinth.com/mod/farmers-delight">Farmer's Delight</a> that adds a variety of new **Cutting Board** variations, each crafted from different wood types - including compatibility with popular mods - bringing even more personalization to your Minecraft kitchen!

**I'm still actively developing this mod, so stay tuned for more features!**
